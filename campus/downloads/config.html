Three wizard steps

The wizard tells you to learn ports for the applications you use, then FQDNs and IP addresses for your cluster, then FQDNs and IP addresses for voice.

Cluster kinds

The connectivity requirements page defines commercial as the standard environment, FedRAMP as an isolated U.S. federal environment with continuous monitoring and restricted access, and a sovereign cloud as a region that keeps data residency and operations inside a country’s legal boundary.

If you do not know the cluster, the page says to ask the account representative. Do not guess na1.

Checklist you can actually run

Select only the applications in the ports checklist that the tenant uses. Copy that result, not this whole table.

Allow paired ranges. The IP address page says a missing range is a failover risk.

Integrated Softphone has its own allowlist, including a separate FedRAMP list, reached through the wizard.

Require TLS 1.2 and at least one listed cipher in each direction before you call the integration done.
