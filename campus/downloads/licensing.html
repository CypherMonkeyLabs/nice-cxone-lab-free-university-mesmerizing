Licenses and badges

Named gates

CRM Ticketing requires a CRM Ticketing license, and the search permission still matters.

Migrated Calls requires the Migrated Interactions Upload license and the upload permission.

AutoSummary must be enabled with the account representative. Using it with MAX, rather than an agent application, also needs a Copilot for Agents license.

Salesforce CRM integration is billed by how many employees have the Agent Integrations attribute enabled. That is not a public price.

Interaction Analytics widgets require the Interaction Analytics license. Performance Management (Native) changes how much history a widget can show.

Release notes say some features need a purchased license or a public preview signup. From 26.3, Controlled Release is renamed Public Preview.

Badges, without exam fiction

This campus links the badge pages. It does not print exam codes, passing scores, or prices that those pages were not quoted for.
