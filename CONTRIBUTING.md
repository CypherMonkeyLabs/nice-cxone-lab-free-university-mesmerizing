# Contributing

Contact Path is independent study material. It is not affiliated with NiCE.

- Code you add is MIT. Lesson text and drawings you add are CC BY-NC-SA 4.0, matching `LICENSE`.
- Quote this lab's own sentences in the chat index. Do not paste vendor manuals, images, or problem sets.
- Facts that can move (prices, limits, versions, availability) stay tied to a source id and a checked date. If the date is only a month, say so. If a page was not opened, say unconfirmed.
- The author line is "Cypher Monkey, a lifelong student and AI builder." Do not add income claims, LinkedIn, or Spotify.
- Run `node scripts/validate_lessons.mjs`, `python3 scripts/licence_manifest.py`, `python3 scripts/csp_check.py`, and `node scripts/verify.mjs` before you open a pull request.
- Do not lower the chat confidence floor to make a score look better.
